# Cognitive Alignment Test - Sonnet 3.7

This project implements a cognitive alignment test that helps users understand their thinking and processing styles. The test measures four key dimensions of cognitive processing:

1. **Processing Speed**: Deep Thinker vs. Fast Processor
2. **Abstraction Level**: Concrete vs. Abstract Thinker
3. **Information Focus**: Detail Tracker vs. Pattern Seeker
4. **Communication Style**: Reflective vs. Expressive Communicator

## Features

- Interactive quiz with progress tracking
- Detailed results with radar chart visualization
- Personalized descriptions of cognitive styles
- Option to compare compatibility with others
- Save results for future reference
- Responsive design for all devices

## Legal & Ethical Guidelines

This test follows appropriate ethical guidelines:

- It's presented as a tool for self-reflection and fun, not a diagnostic instrument
- No claims of medical or psychological diagnosis
- Clear disclaimers about the test's purpose
- No collection of personal identifying information
- Results are stored locally only if the user chooses to save them

## Technical Implementation

- Pure HTML, CSS, and JavaScript (no frameworks required)
- Chart.js for data visualization
- Responsive design that works on mobile and desktop
- Local storage for optional result saving

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser
3. No build process or dependencies to install

## Customization

You can easily customize this test by modifying:

- `questions.js` - Add or modify test questions and dimensions
- `styles.css` - Change colors, layout, and styling
- `script.js` - Adjust scoring algorithms or result interpretation
